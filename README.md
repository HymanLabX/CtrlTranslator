# CtrlTranslator

Windows 全局划词翻译工具。在**任何程序**里选中文字，**快速双击 Ctrl 键**，
鼠标旁边就会弹出译文。

翻译由你自己的大模型 API 完成，支持 DeepSeek、智谱、通义、Kimi、硅基流动、
OpenRouter、本地 Ollama 等任何 **OpenAI 兼容**的服务。

---

## 下载

去 [Releases](../../releases/latest) 页面下载 **`CtrlTranslator-Setup-*.exe`**，双击安装即可。
默认装在你的用户目录下，**不需要管理员权限、不弹 UAC**；安装向导里也可以选「为本机所有用户安装」。

装完之后**不用再手动来这里下载了** —— 程序会自己发现新版本并提示一键更新，
详见下面「[自动更新](#自动更新)」。

如果下载或运行时杀毒软件弹了拦截提示，不是电脑中毒了，
看下面「[杀毒软件可能误报](#2-杀毒软件可能误报)」。

> **首次运行会弹一次「Windows 已保护你的电脑」**：安装包目前没有代码签名，
> 点提示框里的「更多信息」→「仍要运行」就能装，之后不会再弹。
> 为什么不签、以后会不会签，见 [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md)。

## 怎么用

1. 在浏览器、Word、PDF 阅读器、微信……任何地方**选中一段文字**
2. **快速连按两下 Ctrl**
3. 译文弹出来

就这样。中文会译成英文，外文会译成中文，自动判断方向。

**划单个单词**会给出音标、词性、几个释义和一个例句；**划句子或段落**只给译文。
日文、韩文也会翻成中文。

浮窗最上面一行是你划到的原文（太长时掐头留尾），用来确认划得对不对。
浮窗上的按钮：🔊 朗读原文 · ☆ 收藏进生词本 · 📋 复制译文 · 📌 钉住不消失 · ✕ 关闭。
按住浮窗空白处可以拖动窗口。按 `Esc` 或点窗外关闭。

划词时软件会悄悄按一次 Ctrl+C 取字，取完再把你剪贴板里原来的东西**原样放回去** ——
文字、截图、复制的文件都一样，不会被弄丢。

### 浮窗嫌大 / 嫌小 / 太刺眼

**设置 → 常规 → 翻译浮窗**，三样各挑一个就行，下次划词生效：

| 浮窗大小 | 字体大小 | 浮窗配色 |
|---|---|---|
| 紧凑 / 标准 / 宽松 | 小字 / 标准 / 大字 | 浅色 / 深色 / 护眼 |

**配色只影响浮窗**，主窗口始终是浅色的。

### 想慢慢看：深度翻译

左键点托盘图标打开主窗口 →「深度翻译」。把一段文字粘进去（最多 5000 字），
一次拿到**译文 + 例句 + 常见搭配**，适合写论文、写邮件时琢磨"该怎么说"。
这一页的结果不进翻译历史；它比划词慢，在等结果时照样可以随手划词。

### 一次翻很长一段

超过 2000 字会先问你确不确定（量大、费额度）。点了「翻译」之后，软件会按长度多等一会儿
（最多 2 分钟），不再像以前那样一过 15 秒就报超时。要是译文写到上限被截断了，
浮窗会明确告诉你，并带一个「去设置」把「最大输出长度」调大。

## 第一次使用：配置翻译服务

第一次启动会自动弹出引导向导，跟着走完就行。你需要准备一个 **API Key**。

### 去哪申请

| 服务商 | 申请地址 | 推荐模型 |
|---|---|---|
| DeepSeek | https://platform.deepseek.com | `deepseek-v4-flash` |
| 智谱 GLM | https://open.bigmodel.cn | `glm-4-flash` |
| 阿里通义 | https://bailian.console.aliyun.com | `qwen-turbo` |
| 硅基流动 | https://siliconflow.cn | 列表里选一个小模型 |

划词翻译**对速度敏感、对模型规模不敏感**，选便宜的快模型就好，
一个月的用量通常只要几块钱。

用**本地 Ollama**（数据不出本机）的话不需要 API Key，向导里选「本地 Ollama」、Key 留空即可。

### ⚠️ 一定要关掉「思考模式」

现在很多模型默认会先"思考"很久再回答。用来聊天很好，**用来划词翻译是灾难** ——
一句话要等十几秒，而且思考产生的字数按输出计费，特别贵。

软件默认已经帮你关掉了。如果你换了服务商发现变慢：

到「设置 → 翻译模型 → 高级设置 → 额外请求参数」，点你这家服务商对应的预设按钮即可
（`DeepSeek / 智谱：关闭思考`、`通义 / 硅基流动：关闭思考`、`OpenAI：最低推理`）。

关思考的写法各家不一样，所以这是**跟着模型走**的设置，不是全局开关 ——
换了服务商就重新点一次对应的预设按钮。浮窗上冒出"模型正在思考"的黄条时，
点黄条上的「关闭思考模式」也行，软件会按你这家服务商的写法自动填好并立刻重译。

关掉之后，翻一句话通常在 **1 秒内**完成。

### 电脑上开了代理软件（Clash 之类）

软件按 Windows 的系统代理设置联网。代理软件退出了、系统代理设置却还留着的时候，
软件会**自动改为直连**再试一次（DeepSeek、智谱、通义这些国内服务本来就不需要代理），
浮窗底下用一行小字告诉你。如果直连也连不上，报错会直接点名是代理没开。

## 配多个服务商，一个挂了自动换下一个

**设置 → 翻译模型** 里可以存好几套配置（DeepSeek、智谱、硅基流动……），
每套都有自己的地址、Key、模型和参数。**拖动卡片排个序，顺序就是降级顺序**。
新建的模型要先点「开始检测」、检测通过才会加进列表，填了一半的不会混进来。

当前这套遇到**秒级失败**时（Key 失效、余额不足、被限流、服务商 5xx、连不上网），
软件会自动改用下一套重试，最多再试 2 个。译文照常弹出来，只在浮窗底下多一行小字
告诉你换了谁。

- **限流、5xx、断网**这类过一会儿自己就好的故障，不做任何记号，下次照常先用你的主力
- **Key 废了、余额空了、模型名不存在**这类你不动手就永远好不了的，会给这个档案打上
  ⚠ 失效标记、跳过它、并**弹一次气泡告诉你**。到设置里把 Key 改对，标记自动消失
- **超时不触发降级** —— 已经等了十秒再换一家只会让你等更久，所以直接报错

只配一套也完全没问题，行为跟以前一模一样。

## 自动更新

启动后过一会儿、以及之后每 24 小时，程序会安静地问一次 GitHub 有没有新版本。
有的话弹一个窗给你看更新说明，你点「立即更新」，剩下的它自己干完：

**下载 → 校验 SHA256 → 静默安装 → 自动把程序重新拉起来。**

- **校验不通过就丢弃**，绝不执行。自动更新说白了就是"从网上下个 exe 然后运行它"，
  没有校验这一步，就等于给自己开了个远程代码执行的口子。校验值直接取自 GitHub
  Releases API 给出的资产摘要（就是资产列表里显示的那个 `sha256:…`），
  **不需要额外发一个校验文件**
- **只走 GitHub 直连**，不做任何第三方镜像回退。国内没代理时下载几十 MB 容易断，
  断了会告诉你，也可以点「打开发布页面」自己下
- **不会推预发布版**：`rc` / `beta` 那些 tag 不会被推给你
- 点了「稍后」的版本**不再重复弹窗**，但设置页里仍然看得到，随时能装
- **完全不想它联网**：设置 → 关于 → 取消勾选「自动检查新版本」。也可以随时手动点「检查更新」，
  结果会如实告诉你是"已经是最新版"、"查不到发布信息"还是"连不上 GitHub"

装在 `Program Files`（安装时选了"为本机所有用户"）的话，更新会弹一次 UAC —— 绕不开，
装在默认的用户目录则全程无提示。

> 如果你用的是从 `publish\` 拷出来的裸 exe，程序会认出来并提示你去下载安装包版：
> 裸 exe 没法安全地自我更新（"下载 exe → 替换自己 → 重启"这套动作在杀毒软件眼里
> 几乎等同蠕虫），所以 Release 里不再提供它。

## 找不到托盘图标？

**这是正常现象，不是软件出问题了。**

Windows 默认把新出现的托盘图标折叠进任务栏右下角的 **`^`** 箭头里，不直接显示。

**点一下 `^` 就能看到它。**

想让它一直显示在任务栏上，二选一：

- 在 `^` 弹出的面板里，**把 CtrlTranslator 图标拖到任务栏上**
- 或者：设置 → 个性化 → 任务栏 → 选择哪些图标显示在任务栏上 → 打开 CtrlTranslator

> 顺带一提：即使图标折叠着，软件的气泡提示仍然会正常弹出（前提是你没在
> Windows 里关闭全局通知）。

## 已知限制

这两条是设计上绕不开的，装之前请先了解。

### 1. 管理员权限的程序里划不了词

Windows 有个叫 **UIPI** 的安全机制：普通权限的程序收不到高权限程序的按键。

所以在**任务管理器、部分安装程序、某些安全软件**里双击 Ctrl 不会有反应。

**解决办法**：让 CtrlTranslator 也以管理员身份运行（右键 exe → 以管理员身份运行）。
但这样它就需要每次手动启动，开机自启会失效，请自行权衡。

### 2. 杀毒软件可能误报

CtrlTranslator 要做三件事：装全局键盘钩子、模拟按 Ctrl+C、读剪贴板。
**这三件事组合起来正是键盘记录器的典型特征**，所以可能被拦。这是启发式规则误判，
不是软件真的有问题——**这个软件不上传你的任何数据**（除了你主动划词要翻译的那段文字，
发给你自己配置的 API 服务商），源码在 `src/` 下可以自己查，构建流程全公开在
[.github/workflows](.github/workflows/build-and-release.yml)。

**如果被拦了，加白名单：**

- **Windows Defender**：Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
  排除项 → 添加排除项 → 文件 → 选中 `CtrlTranslator.exe`
- **火绒**：拦截提示里选「信任」；或 火绒安全软件 → 工具 → 信任区 → 添加文件
- **360**：拦截提示里选「允许运行」；或 360安全卫士 → 木马查杀 → 信任区管理 → 添加信任
- **腾讯电脑管家**：拦截提示里选「继续运行」；或 电脑管家 → 工具箱 → 信任区 → 添加

如果不放心，可以直接看下面「自己编译」，从源码本地打包，
全程不下载任何人发的二进制文件。

发布产物目前**没有代码签名**，所以上面这些照常适用。签名的架子在发布流程里留着，
以后拿到证书随时能开——原因和可选方案见 [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md)。

> 以前这里还有第三条「剪贴板里的图片会丢」。现在划词会把剪贴板**完整**备份再原样放回，
> 截图、复制的文件、带格式的文字都不会再丢，这条限制已经没有了。
> （极少数用"图元文件"格式放进剪贴板的老程序除外，那种格式没法安全地复制。）

## 数据存在哪 / 怎么卸载

所有数据都在这个目录（在文件资源管理器地址栏粘贴回车即可打开）：

```
%APPDATA%\CtrlTranslator
```

| 文件 | 内容 |
|---|---|
| `settings.json` | 你的配置。**API Key 用 Windows 账户加密存储**，明文不落盘，拷到别的电脑也解不开 |
| `history.db` | 翻译历史和收藏的生词本 |
| `logs\` | 运行日志，按天分文件，自动删除 14 天前的 |

**卸载**：

从托盘退出程序 → 设置 → 应用 → 找到 CtrlTranslator → 卸载。
会自动清掉开机自启注册项；`%APPDATA%\CtrlTranslator` 数据目录**不会**被删，
想连历史和生词本一起清掉就手动删这个目录。

如果你跑的是自己编译出来的裸 exe：从托盘退出 → 删掉 exe → 删掉上面那个目录即可，
本软件不写注册表（除非你打开过「开机自动启动」，那会在
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 留一项，关掉开关即可清除）。

## 出问题了怎么办

**设置 → 翻译模型 → 选中那个模型 → 点「开始检测」**。

它会逐项检查：配置完整性 → 地址格式 → DNS 解析 → 网络连接（开了代理的话会单独检查代理通不通）→
身份认证 → 模型可用性 → 实测翻译延迟 → 是否推理模型 → 语音引擎 → 数据库 → 键盘钩子 → 运行权限，
每项给 ✓ / ✗ / ⚠ 和耗时，结果直接展开在卡片里。**一眼就能看出卡在哪一环。**

浮窗上的报错都写成了人话：Key 错了、余额不足、模型名写错、地址写错、代理没开、
服务商自己出故障……各说各的，不会张冠李戴。点报错下面的按钮就能直接去修。

旁边的「复制诊断报告」按钮会把结果复制成纯文本（API Key 自动脱敏成 `sk-****1234`），
可以直接贴给别人求助。

日志在 `%APPDATA%\CtrlTranslator\logs\`，「设置 → 关于 → 数据管理」里有「打开日志文件夹」。

## v1.0 不包含的功能

以下都在后续版本考虑，现在**没有**：

- 截图 OCR 翻译（翻图片、扫描版 PDF、视频字幕）
- 对译文追问 / 多轮对话
- 整篇文档双语对照
- 多引擎并排对比（多服务商只用于故障降级，不做同时翻译对比）
- 用量与花费统计（token 数已经在默默记录，但没有统计界面）
- 浏览器插件
- 本地离线翻译模型

## 自己编译

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。

```powershell
# 开发运行
dotnet run --project src/CtrlTranslator

# 打包（产物在 publish\ 和 installer\output\）
.\build.ps1
```

打包产物约 73 MB，自包含 —— 目标机器不需要装 .NET 运行时。

> ⚠️ 改完代码后，`publish\CtrlTranslator.exe` **不会自动重新生成**。
> 测试改动请用 `dotnet run`，只有验证打包产物时才需要先跑 `.\build.ps1`。

如果本机装了 [Inno Setup](https://jrsoftware.org/isinfo.php)（`winget install
JRSoftware.InnoSetup`），`build.ps1` 会顺带把 `installer\CtrlTranslator.iss` 编译成
安装包，产物在 `installer\output\`。没装就跳过这一步，不影响 exe 打包。

`publish\CtrlTranslator.exe` 是**自测用**的：拷到哪都能跑，但它没有安装记录，
收不到程序内的一键更新（程序会认出来并提示你去装安装包版）。发给别人请用安装包。

项目文档在 `docs/`：`SPEC.md` 是完整需求规格书，`MILESTONES.md` 是分阶段验收清单。

## 发布新版本

每次推送到 `main` 都会在 GitHub 上自动编译一遍（编译不过会收到邮件）。
要发版本，推一个 `v` 开头的 tag 即可，安装包由 GitHub 自动打包并发布：

```powershell
git tag v0.1
git push origin v0.1
```

**发版前记得把 `CtrlTranslator.csproj` 里的 `Version` / `AssemblyVersion` / `FileVersion`
改成同一个号**，否则装上新版之后程序仍然认为自己是旧版本，会一直提示有更新。

**Release 只有一个资产**：`CtrlTranslator-Setup-<版本>.exe`。
不再发校验文件 —— GitHub 的 Releases API 每个资产自带 `sha256:` 摘要，
自动更新直接用它比对，再发一份纯属冗余。想手动核对的话，
资产列表里 GitHub 就把哈希显示出来了，用 `Get-FileHash` 一比即可。

tag 里带 `rc` / `beta` / `alpha` / `preview` 的会自动标为预发布，
而自动更新只看 `/releases/latest`（天然跳过预发布），所以预发布不会被推给用户。

流程定义在 [.github/workflows/build-and-release.yml](.github/workflows/build-and-release.yml)，
代码签名的现状（不签）和以后怎么开启见 [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md)。
