# CtrlTranslator

Windows 全局划词翻译工具。在**任何程序**里选中文字，**快速双击 Ctrl 键**，
鼠标旁边就会弹出译文。

翻译由你自己的大模型 API 完成，支持 DeepSeek、智谱、通义、Kimi、硅基流动、
OpenRouter、本地 Ollama 等任何 **OpenAI 兼容**的服务。

---

## 怎么用

1. 在浏览器、Word、PDF 阅读器、微信……任何地方**选中一段文字**
2. **快速连按两下 Ctrl**
3. 译文弹出来

就这样。中文会译成英文，外文会译成中文，自动判断方向。

**划单个单词**会给出音标、词性、几个释义和一个例句；**划句子或段落**只给译文。

浮窗上的按钮：🔊 朗读原文 · ☆ 收藏进生词本 · 📋 复制译文 · 📌 钉住不消失 · ✕ 关闭。
按住工具条空白处可以拖动窗口。按 `Esc` 或点窗外关闭。

## 第一次使用：配置翻译服务

第一次启动会自动弹出引导向导，跟着走完就行。你需要准备一个 **API Key**。

### 去哪申请

| 服务商 | 申请地址 | 推荐模型 |
|---|---|---|
| DeepSeek | https://platform.deepseek.com | `deepseek-v4-flash` |
| 智谱 GLM | https://open.bigmodel.cn | `glm-4-flash` |
| 阿里通义 | https://bailian.console.aliyun.com | `qwen-turbo` |
| 硅基流动 | https://siliconflow.cn | 列表里选一个小模型 |

划词翻译**对速度敏感、对模型规模不敏感**，选便宜的快模型就好，
一个月的用量通常只要几块钱。

### ⚠️ 一定要关掉「思考模式」

现在很多模型默认会先"思考"很久再回答。用来聊天很好，**用来划词翻译是灾难** ——
一句话要等十几秒，而且思考产生的字数按输出计费，特别贵。

软件默认已经帮你关掉了。如果你换了服务商发现变慢：

- **右键托盘图标 → 勾上「关闭模型思考模式」**，这是最快的办法
- 或者到「设置 → 翻译服务 → 额外请求参数」，点对应服务商的预设按钮

关掉之后，翻一句话通常在 **1 秒内**完成。

## 找不到托盘图标？

**这是正常现象，不是软件出问题了。**

Windows 默认把新出现的托盘图标折叠进任务栏右下角的 **`^`** 箭头里，不直接显示。

**点一下 `^` 就能看到它。**

想让它一直显示在任务栏上，二选一：

- 在 `^` 弹出的面板里，**把 CtrlTranslator 图标拖到任务栏上**
- 或者：设置 → 个性化 → 任务栏 → 选择哪些图标显示在任务栏上 → 打开 CtrlTranslator

> 顺带一提：即使图标折叠着，软件的气泡提示仍然会正常弹出（前提是你没在
> Windows 里关闭全局通知）。

## 已知限制

这三条是设计上绕不开的，装之前请先了解。

### 1. 管理员权限的程序里划不了词

Windows 有个叫 **UIPI** 的安全机制：普通权限的程序收不到高权限程序的按键。

所以在**任务管理器、部分安装程序、某些安全软件**里双击 Ctrl 不会有反应。

**解决办法**：让 CtrlTranslator 也以管理员身份运行（右键 exe → 以管理员身份运行）。
但这样它就需要每次手动启动，开机自启会失效，请自行权衡。

### 2. 杀毒软件可能误报

CtrlTranslator 要做三件事：装全局键盘钩子、模拟按 Ctrl+C、读剪贴板。
**这三件事组合起来正是键盘记录器的典型特征**，所以可能被拦。

**如果被拦了，加白名单：**

- **Windows Defender**：Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
  排除项 → 添加排除项 → 文件 → 选中 `CtrlTranslator.exe`
- **火绒 / 360 / 电脑管家**：在弹出的拦截提示里选「允许」或「信任」，
  或到「信任区 / 白名单」里手动添加

这个软件不上传你的任何数据（除了你主动划词要翻译的那段文字，发给你自己配置的
API 服务商），源码在 `src/` 下可以自己查。

### 3. 剪贴板里的图片会丢

取词的原理是"偷偷按一下 Ctrl+C，取完再把你原来的剪贴板内容还回去"。

v1.0 **只能还原文字**。如果你剪贴板里当时是图片或文件，划词之后它会没掉。

日常使用中这种情况不多，但如果你刚截了图还没粘贴，先粘完再划词。

## 数据存在哪 / 怎么卸载

所有数据都在这个目录（在文件资源管理器地址栏粘贴回车即可打开）：

```
%APPDATA%\CtrlTranslator
```

| 文件 | 内容 |
|---|---|
| `settings.json` | 你的配置。**API Key 用 Windows 账户加密存储**，明文不落盘，拷到别的电脑也解不开 |
| `history.db` | 翻译历史和收藏的生词本 |
| `logs\` | 运行日志，按天分文件，自动删除 14 天前的 |

**彻底卸载**：从托盘退出程序 → 删掉 `CtrlTranslator.exe` → 删掉上面那个目录。
本软件不写注册表（除非你打开过「开机自动启动」，那会在
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 留一项，关掉开关即可清除）。

## 出问题了怎么办

**设置 → 翻译服务 → 一键诊断**。

它会逐项检查：配置完整性 → 地址格式 → DNS 解析 → 网络连通 → 身份认证 →
模型可用性 → 实测翻译延迟 → 是否推理模型 → 语音引擎 → 数据库 → 键盘钩子 → 运行权限，
每项给 ✓ / ✗ / ⚠ 和耗时。**一眼就能看出卡在哪一环。**

底部「复制诊断报告」按钮会把结果复制成纯文本（API Key 自动脱敏成 `sk-****1234`），
可以直接贴给别人求助。

日志在 `%APPDATA%\CtrlTranslator\logs\`，托盘菜单里有「打开日志文件夹」。

## v1.0 不包含的功能

以下都在后续版本考虑，现在**没有**：

- 截图 OCR 翻译（翻图片、扫描版 PDF、视频字幕）
- 对译文追问 / 多轮对话
- 输入框手动翻译
- 整篇文档双语对照
- 多引擎并排对比
- 自动更新
- 浏览器插件
- 本地离线翻译模型

## 自己编译

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。

```powershell
# 开发运行
dotnet run --project src/CtrlTranslator

# 打包成单文件 exe（产物在 publish\）
.\build.ps1
```

打包产物约 73 MB，自包含 —— 目标机器不需要装 .NET 运行时。

项目文档在 `docs/`：`SPEC.md` 是完整需求规格书，`MILESTONES.md` 是分阶段验收清单。
