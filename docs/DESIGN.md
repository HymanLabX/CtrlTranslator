# CtrlTranslator 视觉设计规格书

> 视觉方向：**ChatGPT 风格的浅色 AI 工作台**。
> 借鉴其白色内容画布、浅灰导航、克制控件与内容优先的层级，但保留 CtrlTranslator 自己的品牌和桌面工具交互。
> `SPEC.md` 管功能，本文件管视觉与布局；冲突时功能、稳定性和可用性优先。
>
> **本文件描述的是当前代码里的实际状态**，不是待办清单。改了界面就要回来改这里；
> 发现对不上，以代码为准并修正本文件。

---

## 0. 改造边界

这是视觉重构，不是功能扩张。

- 所有翻译、取词、收藏、朗读、诊断、更新和设置功能保持不变。
- 深度翻译、应用设置、翻译历史统一位于主窗口侧栏；收藏作为翻译历史页的内容筛选，不占一级导航。
  设置必须在同一主窗口内切换，不创建第二个顶级窗口。
- 不把软件改成聊天界面，不增加消息气泡、输入提示框、对话角色或聊天历史概念。
- 不复制 OpenAI / ChatGPT 标志；品牌区直接使用程序自身的 `ctrltranslator.ico`。
- 不改变浮窗 `ShowActivated`、`Topmost`、`SizeToContent`、外部点击关闭和钉住行为。
- 不引入第三方 UI、字体、图标或动效依赖。
- 主窗口、设置页和向导只提供一套浅色主题，不跟随系统深浅色。
- **例外：翻译浮窗可以换配色**（浅色 / 深色 / 护眼 / 自定义），见 §5.5。
  这只作用于浮窗那一扇窗口，靠往 `PopupWindow.Resources` 里塞同名画笔实现，
  不是全局深色主题，其余界面一个像素都不变。

## 1. 设计原则

1. **内容优先**：历史原文、译文和当前翻译结果是视觉中心，界面镀铬退居其次。
2. **中性克制**：黑、白、浅灰构成主色；绿色只表达"已就绪、成功、安全"等状态。
3. **轻边界**：主要靠留白和浅灰表面分区，边框只做必要的结构提示。
4. **层级不能是反的**：任何标题都必须比它统领的内容更重（更大或更深），
   不允许出现"二级标题比正文还小还浅"这种把层级倒过来的写法。
5. **同一组里只用一种交互**：同一张卡片里的同类参数，要么都是输入框、要么都是滑杆，
   不混用——混用会让人每读一项就切换一次心智。
6. **原生效率**：布局适合鼠标与键盘，长表单可滚动。
7. **不是网页**：保留标准 Windows 标题栏、窗口缩放、DPI 和托盘行为。

### 1.1 明确舍弃

- 不使用旧版暖纸色、米黄色背景和电子墨水质感。
- 主界面不使用深色主题、紫蓝渐变、霓虹光、玻璃拟态和大面积阴影（浮窗配色是上面那条的独立机制）。
- 不使用网页营销式巨型标题、大留白或滚动揭示动效。
- 不使用 emoji、彩色位图图标或 Unicode 字符模拟工具图标。
- 不使用外部在线字体。
- 不用"小写灰色眉标"当分组标题：西文靠大写 + 字距立得住，中文没有大小写，学不来。

## 2. 设计令牌

全部定义在 `Themes/Tokens.Light.xaml`。窗口和代码里的动态内容只能引用资源，禁止硬编码颜色。

### 2.1 颜色

| 令牌 | 值 | 用途 |
|---|---:|---|
| `Color.Bg` | `#FFFFFF` | 窗口底 |
| `Color.Surface` | `#FFFFFF` | 内容区、列表、卡片 |
| `Color.SurfaceRaised` | `#FFFFFF` | 菜单、提示、浮窗外壳 |
| `Color.SurfaceSubtle` | `#F7F7F8` | 工作区底、输入、只读区 |
| `Color.NavPrimary` | `#F2F2F3` | **一级导航（主窗口侧栏）** |
| `Color.NavSecondary` | `#F9F9FA` | **二级导航（设置目录列）** |
| `Color.Border` | `#E5E5E5` | 常规边框 |
| `Color.BorderSoft` | `#EDEDEE` | **设置行分隔线、卡片内分隔线** |
| `Color.BorderStrong` | `#D1D1D1` | 输入悬停、浮窗外框、导航分界 |
| `Color.Text` | `#171717` | 正文与标题 |
| `Color.TextSecondary` | `#5D5D5D` | 说明与次要信息 |
| `Color.TextTertiary` | `#8F8F8F` | 元信息、占位、禁用信息 |
| `Color.Accent` | `#171717` | 主按钮、焦点、选中边框 |
| `Color.AccentHover` | `#2F2F2F` | 主操作悬停 |
| `Color.AccentPressed` | `#000000` | 主操作按下 |
| `Color.AccentSubtle` | `#ECECEC` | 选中项背景 |
| `Color.AccentSecondary` | `#0D8F72` | AI / 安全 / 就绪辅助色，导航选中条 |
| `Color.Hover` | `#F3F3F3` | 通用悬停 |
| `Color.Pressed` | `#E8E8E8` | 通用按下 |
| `Color.Success` / `SuccessBg` | `#0D8F72` / `#E8F7F2` | 成功 |
| `Color.Warning` / `WarningBg` | `#9A6700` / `#FFF8E6` | 警告 |
| `Color.Danger` / `DangerBg` | `#D00E17` / `#FFF0F1` | 错误与危险操作 |
| `Color.OnAccent` | `#FFFFFF` | 近黑主按钮上的文字 |
| `Color.Transparent` | `#00FFFFFF` | 显式透明（不要写字面 `Transparent`） |

**三级底色不是可有可无的**：旧版侧栏 `#F3F3F3` 和工作区 `#F7F7F8` 只差一档，
实机上肉眼分不出那是两块区域，只好靠投影去补偿。现在
`NavPrimary → NavSecondary / SurfaceSubtle → Surface` 本身就拉开了层级，投影就成了多余的镀铬。

### 2.2 字体

| 令牌 | 字体 |
|---|---|
| `Font.Ui` | `Segoe UI Variable Text, Segoe UI, Microsoft YaHei UI, Microsoft YaHei` |
| `Font.Display` | `Segoe UI Variable Display, Segoe UI, Microsoft YaHei UI, Microsoft YaHei` |
| `Font.Mono` | `Cascadia Mono, Consolas, Courier New` |

| 令牌 | 字号 | 用途 |
|---|---:|---|
| `Size.Caption` | 11 | 元信息、状态、来源说明 |
| `Size.BodySmall` | 12 | 行内辅助说明 |
| `Size.Body` | 14 | 默认正文和按钮 |
| `Size.BodyLarge` | 15 | 浮窗译文、品牌名 |
| `Size.Subheading` | 16 | **分组标题（必须大于正文 14）** |
| `Size.Title` | 17 | 向导 / 设置里的卡片标题 |
| `Size.Heading` | 22 | 页面标题 |
| `Size.Display` | 30 | 欢迎页主标题 |

- 隐式 `TextBlock` 的 `LineHeight` 是 **20.3**（`Controls.xaml`）。凡是按行数算高度的地方
  （比如历史卡片折叠成两行 = `MaxHeight="41"`）都从这个数推，不要拍脑袋。
- 浮窗译文行距 1.65。
- 字重仅用 Normal / Medium / SemiBold。

### 2.3 间距、圆角和尺寸

- 圆角：`Radius.Small` 8（输入、**按钮**、分段控件）｜
  `Radius.Medium` 10（历史卡片、服务商卡片、提示条）｜
  `Radius.Large` 14（大面板）｜`Radius.Popup` 14（浮窗）｜`Radius.Pill` 999。
- 页面内边距统一 `32,26,32,26`（历史页、深度翻译页、设置各分区）。
- 控件高度分两档，**按语义选，不要混**：
  - **40**：页面级主操作和工具条控件（`Button.Primary`、隐式 `Button` / `TextBox` / `ComboBox` 的 `MinHeight`）
  - **32**：设置行里的行内控件（`RowTextBox` / `RowComboBox` / `RowPasswordBox`）
- 设置行 `Row` 最小高度 52、`Padding="0,9"`、底部 1px `BorderSoft`。
- 图标按钮 `Button.Icon` 基准 36×36。比基准小的地方必须同时覆盖 `Width` / `Height` / `MinHeight` 三项：
  浮窗内容操作 24（朗读 / 收藏 / 复制）、浮窗窗口控制 26（`WindowControl`）、
  历史卡片操作 28（`CardActionButton`）。深度翻译页的复制按钮用基准 36。
  设置页已经没有纯图标按钮了。
  下限是 **24**（WCAG 2.5.8 的最小目标尺寸），不再往下走。

> ⚠️ `Space.4` … `Space.48` 这组令牌当前**没有任何地方引用**，
> `Effect.SidebarShadow` 和 `Effect.CardGlow` 同样无人引用。留着不碍事，但别当成规范在用。

### 2.4 阴影和动效

- 卡片一律不使用阴影，靠白底、浅灰边框和留白分层。
- 浮窗使用 `Effect.PopupShadow`：**模糊 22、深度 4、透明度 0.22**。
  收窄过一次——blur 28 / depth 6 在 480px 的小窗上糊得偏散，边缘反而不清楚。
  WPF 一个元素只能挂一个 `Effect`，做不了"远近两层阴影"，那就把这一层调实。
- 悬停背景过渡 160ms；按下即时反馈。
- 浮窗仅做 160ms 透明度淡入，不位移、不缩放、不弹跳。
- 加载环 800ms 匀速旋转；不做其他循环装饰动画。

## 3. 控件系统

### 3.1 按钮

| 样式 | 外观 | 用途 |
|---|---|---|
| `Button.Primary` | 近黑实底、白字、MinHeight 40 | 当前页面唯一主操作 |
| `Button.Secondary` | 白底、浅灰边框 | 普通操作 |
| `Button.Ghost` | 透明底，悬停浅灰 | 侧栏和弱操作 |
| `Button.Icon` | 单色图标，尺寸由使用处给 | 浮窗、卡片、行内快捷操作 |

- 五态齐全：Normal / Hover / Pressed / Disabled / Focused。
- 键盘焦点使用清晰的近黑描边，不显示系统虚线框。
- 禁用透明度 0.42，禁用态不播放悬停动画。
- ⚠️ `_` 在 `Button.Content` 里是访问键助记符，会被吞掉。要显示下划线得写 `__` 或改用
  `<TextBlock>` 承载。

### 3.2 输入类

- `SurfaceSubtle` 背景、1px `Border`、`Radius.Small`、悬停边框 `BorderStrong`、聚焦 2px `Accent`。
- 输入值用 `Text`，占位和说明用 `TextTertiary`。
- JSON 和 Prompt 编辑框使用 `Font.Mono` 并保留滚动条。
- ⚠️ 自定义样式必须写 `BasedOn="{StaticResource {x:Type TextBox}}"`。
  WPF 的显式 `Style` 是**替换**隐式样式而不是合并，忘了 `BasedOn` 会把自定义模板整个顶掉——
  表现是同一行里两个输入框长得不一样。
- ⚠️ 改高度要同时给 `Height` 和 `MinHeight`：隐式样式里的 `MinHeight` 会压过单独的 `Height`。
  改完高度还要顺手收 `Padding`（32 高配 `10,4` 只剩 22px 装 20.62px 的文字，字会被切）。

### 3.3 设置行（`Row`）

一条设置 = 左边名称 + 下面一行灰色说明 + 右边控件。

- 名称 `RowName`：`Size.Body`（14），默认色。
- 说明 `RowHint`：`Size.BodySmall`（12）、`TextTertiary`、可换行。
  数值项的说明必须同时写**单位和有效范围**，例如"毫秒；150–800"。
- 右侧控件宽度统一 120，`Margin="20,0,0,0"`，数值框 `TextAlignment="Center"`。
- 开关用 `ToggleSwitch`：40×22 的轨道装在 44×32 的命中区里。
- 分组标题 `SectionLabel`：`Size.Subheading`（16）SemiBold `Text`，下边距 12。
- 页面标题 `PageTitle`：`Font.Display` + `Size.Heading`（22）SemiBold。

### 3.4 导航

**一级：主窗口侧栏**

- 固定宽 **180**，底色 `NavPrimary`，右侧 1px `BorderStrong`，`Padding="10,14"`，**不加投影**。
- 品牌区：程序图标 24×24 + `Size.BodyLarge` 名称，间距 9，左边距 12。
  这个 12 不是随手取的——导航项的内容起点 = 3px 选中条 + 9px 间距 = 12，
  品牌图标要和下面的导航图标落在同一条左边线上。
- 三项，自上而下：**深度翻译 / 应用设置 / 翻译历史**。
- 选中态：`Surface` 底 + `Border` 边框 + 3px `AccentSecondary` 左条 + SemiBold。
  颜色、字重、左条三重冗余，不只靠颜色。
- 侧栏不展示"已就绪 / 划词翻译已开启"等常驻状态；划词开关在"应用设置 → 常规"里管。

**二级：设置目录列**

- 宽 **196**，底色 `NavSecondary`，右侧 1px `BorderSoft`，`Padding="10,14"`。
- 四项：常规 / 翻译模型 / 翻译偏好 / 关于，每项 16px 图标 + 文字，`MinHeight` 32。
- 即时保存状态条 `StatusText` 停在目录列底部（`DockPanel.Dock="Bottom"`），
  不再占内容区一整条横带。

**分段筛选（`ContentFilterToggle`）**

- 现在只剩"全部 / 已收藏"一处在用，语义收敛为**筛选**。
  设置分类改用左侧目录之后，分段控件不再兼职表示"分类"，两种含义不再打架。
- 紧凑圆角矩形，不用椭圆胶囊；选中用 `AccentSubtle` 底 + 边框 + SemiBold。

### 3.5 卡片和列表

- 卡片白底、1px `Border`、`Radius.Medium`，悬停 `BorderStrong`，选中 `Accent`。
- 不使用交替底色。
- 所有选中状态都不能只依赖颜色。
- 服务商卡片 `ProfileCard`：**不写死宽度**，外层 `UniformGrid Columns="3"` 等分列、卡片跟着列宽拉伸；
  固定高 88，`Margin="0,0,12,12"`。

### 3.6 滚动条和进度条

- 滚动条宽 10（横向时高 10），无箭头；滑块中灰，悬停加深。
- ⚠️ `Track` 必须显式写 `ViewportSize="{TemplateBinding ViewportSize}"`。
  `ScrollBar` 只自动接 `Minimum` / `Maximum` / `Value` 到 `PART_Track`，`ViewportSize` 不接；
  拿不到就是 `NaN`，`Track` 退化成"滑块给个最小值"——屏幕上是一个浮着的小圆点。
- 确定进度使用 6px 近黑进度条。
- 不确定等待使用旋转环和实时文字。

## 4. 图标系统

- 图标是 16×16 坐标系 `Geometry`，统一放在 `Themes/Icons.xaml`。
- 1.5px 圆头圆角描边，颜色由使用处决定。
- 默认 `TextSecondary`，悬停 `Text`，激活 `Accent`。
- 不使用 OpenAI 标志，不使用 emoji，不使用在线图标库。
- 图标按钮必须有简体中文 `ToolTip` 和 `AutomationProperties.Name`。
- 当前清单：`Speaker` `Stop` `Star` `StarFilled` `Copy` `Check` `Pin` `Close` `Search` `Trash`
  `Settings` `Pulse` `Refresh` `Download` `Folder` `Warning` `Error` `Info` `History`
  `Swap` `Preference` `Book` `Dot` `Circle`。
- `Dot` / `Circle` 是引导向导的步骤状态标记（当前 / 未开始）。圆按 `Icon.Error` 的写法
  拆成两段 180° 弧 —— WPF 的路径语法没有整圆命令。

## 5. 窗口规范

### 5.1 主窗口

- 默认 1120×720，最小 900×600。
- 左侧 180px 侧栏（§3.4），右侧内容区。
- Windows 标题栏始终只显示 `CtrlTranslator`，不拼接当前页面名。
- 主窗口是深度翻译、翻译历史与设置的唯一顶级窗口；切换页面时不改变窗口位置与尺寸。

### 5.2 翻译历史页

**结构：单列卡片流，没有右侧详情栏。**

之前是左列每行只显示原文、右边一整块常驻详情栏伺候一条记录——两栏都在为同一条记录服务，
却各自只显示一半，右边大部分时间空着。"右边一大片空白"不是留白没调好，是那个结构的必然结果。

- 页头：`Size.Heading` 标题 + 一行 `TextSecondary` 说明。
- 搜索框和"全部 / 已收藏"压在列表正上方（原来摆在整页右上角，离自己管的东西隔着大半个窗口）。
  搜索框吃掉剩余宽度、筛选靠右固定，最小窗口 900 宽时仍排得开。搜索输入 220ms 防抖。
- 每张卡：`Padding="15,13"`、`Margin="0,0,0,10"`、`Radius.Medium`、白底 1px `Border`。
  上半原文（`Text`），1px `BorderSoft` 分隔线，下半译文（`TextSecondary`）。
- **折叠时两半各最多两行**（`MaxHeight="41"`，即 2 × 20.3），带 `CharacterEllipsis`；
  折叠态的文本先经 `SingleLineConverter` 压成单行，否则原文里的换行会先把两行额度吃光。
- **点卡片展开完整内容并显示来源说明，再点一次收起。**
  来源说明只在展开态出现：模型 · 服务商 · 来自哪个程序 · 耗时。折叠时它是噪音。
- 操作按钮 28×28，平时 0.55 透明度、鼠标移到卡上变实。**不做完全隐藏**——那样第一次用的人
  根本不知道卡片上有操作；收藏态是实心深色星，半透明下也认得出来。
  复制原文 / 收藏 / 删除跟着原文那半边，复制译文跟着译文那半边——
  **位置本身说明了复制的是哪个**，不用去分辨两个长得一样的图标。
- 删除即删，不二次确认。列表不提供右键菜单。
- 每条记录**不显示时间**。滚动到底自动加载下一页。
- 列表右侧留 10px 内边距给滚动条，否则滚动条会压在卡片圆角上。
- 空状态区分"没有搜索结果"和"还没有记录"两种文案。
- **列表就地更新，不整表重载**：新翻译的记录插到顶部、删除就地拿掉、浮窗上点收藏就地改星标。
  整表重载会把滚动位置甩回顶部、把展开的卡片收起——用户只是划了个词或点了颗星。
  有搜索词或开着「已收藏」筛选时新记录先不插，下次回到这一页再整表重载。
- CSV 导出在"应用设置 → 关于"，不占历史页。

### 5.3 深度翻译页

- 页头：`Size.Heading` 标题 + 一行说明，一次答完"这页是干嘛的 / 怎么触发 / 为什么慢 / 会不会影响划词"。
- 工具条：模式下拉 + 译成语言下拉（左），停止 / 翻译按钮（右）。
- 左右两块面板：左 45% 原文输入，右 55% 结果，`Radius.Large` 白底卡片。
- 分组标题（原文 / 译文 / 例句 / 常见搭配）统一 `Size.Subheading`。
- 结果区四态互斥：空状态 / 进行中 / 出错 / 结果。
- 结果下方那行元信息兼做反馈位：复制成功 / 失败的提示在这里停 2 秒再复原，
  不另开弹窗（复制失败是常事，不该打断）；降级、代理直连、输出被截断也追加在这一行。
- 例句左边一道 2px `AccentSecondary` 竖线，与浮窗里的词典例句是同一种视觉物件。
- ⚠️ 模式和语言下拉必须用 `ItemTemplate`，不能图省事写 `DisplayMemberPath`：
  `Controls.xaml` 的 ComboBox 模板走 `SelectionBoxItemTemplate`，
  而它只跟 `ItemTemplate` 走——写成 `DisplayMemberPath` 的话展开的列表项是对的，
  收起来的选中框却显示类型全名。

### 5.5 翻译浮窗

外壳：1px `BorderStrong`、`Radius.Popup`（14）、`Effect.PopupShadow`、`Padding="14,10,14,8"`。

五行结构，自上而下：

1. **原文回显 + 钉住 + 关闭**。原文用 `Size.BodySmall` / `TextTertiary`。
   划词经常划多、划少或划错——译文读着不对时，用户没法判断是模型翻错了还是自己选错了，
   只能关掉重划。回显解决的就是这个。
   过长时**取头尾、中间用括号加省略号**：`simulation（··· ···）hours.`
   - 退让到最近的空格，不把单词从中间劈开；退让超过四成就不退（中文没空格）。
   - 括号跟着原文的语种走：CJK 占比高用全角 `（··· ···）`，否则用半角 `(··· ···)`。
     一段纯英文里突然冒出全角括号，看着反而像原文里本来就有的。
2. 提示条（`Collapsed` 默认）。从底部一大块改成顶部一条细的——它原本比要提示的内容还显眼。
   承载：错误修复入口（红）、推理模型提醒（黄）、**译文不完整**（黄，带「去设置」）。
   译文不完整优先于推理模型提醒——前者是结果本身有缺，后者只是慢和贵。
3. 小字说明行（`Size.Caption` / `TextTertiary`，`Collapsed` 默认）：自动降级到了哪个档案、
   代理没开这次自动直连了。可以同时有两行。刻意不做成醒目的警告条——
   这是软件替用户兜住了故障，不该打断阅读。
4. **内容区**。⚠️ 这一行必须是 `Height="*"`，不能是 `Auto`：
   `SizeToContent="Height"` 撞上 `MaxHeight` 之后，`Auto` 行会按内容的完整高度去要空间，
   把下面那行操作栏整个顶出可视区（长译文时底部按钮直接看不见）。
5. **朗读 / 收藏 / 复制（24×24）+ 右侧 `模型 · 0.5s`**，水平居中对齐。
   这三个是对译文的操作，该跟着内容走；顶部只留钉住和关闭这两个真正的窗口控制，
   第一眼落点才是原文和译文。

其他：

- 窗口控制按钮 26×26，默认 `TextTertiary`，悬停才变实——它们是配角。
  钉住态给足底色和实心，因为"钉住了没有"必须一眼看得出来。
- **拖动挂在整个外壳上**（`ShellBorder.MouseLeftButtonDown`），视觉树里排除内容区和所有按钮。
  之前只有顶部那条 26px 的窄带可拖，太细，稍微瞄低一点就落到内容区，表现是"拖了没反应"。
- 译文字号由"字体大小"预设决定（12 / 14 / 18，或自定义 10–24）。
- 词典结果走结构化渲染（`DictionaryEntryParser`）：词性、释义、例句分层。
  解析不出结构就退回普通译文渲染，不留空白。

#### 浮窗配色（唯一允许换肤的界面）

内置三套 + 一套自定义。每套只写 5 个基准色，其余过渡色按同一规则算出来
（分隔线 = 外框混向底色 50%；次要文字 = 正文混向底色 32%；更弱信息 50%；
悬停 = 底色混向正文 6%，按下 12%），保证不会出现"次要文字比正文还深"这种走样。

| 配色 | 底色 | 外框 | 正文 | 强调 |

| 自定义 | 用户填 | 由正文混向底色 62% 推出 | 用户填 | = 正文 |

- 错误与警告提示条**不参与换肤**：深色底上仍是"浅底深字的一小块"，照样看得清。

### 7.1 WPF 踩坑登记

按 CSS 盒模型的直觉推 WPF 布局，几乎每次都会错。以下每一条都是实际调错过的，别再踩：

| 现象 | 真正的原因 |
|---|---|
| 同一行两个输入框长得不一样 | 显式 `Style` **替换**隐式样式而不是合并，忘了 `BasedOn` |
| 设了 `Height` 却不生效 | 隐式样式里的 `MinHeight` 压过 `Height`，两个都要设 |
| 高度对了但文字被切 | 高度收窄后 `Padding` 没跟着收 |
| `ClearValue` 清不掉属性 | `ClearValue` 只清本地值，清不掉样式 Setter |
| 内容居中了但还是偏 | 只在自己那列居中；要用触发器让它 `Grid.ColumnSpan` 跨过旁边的箭头列 |
| 滚动条变成一个浮着的小圆点 | `Track` 没接 `ViewportSize`，值是 `NaN` |
| `Visibility.Hidden` 的元素还占位 | 要用 `Collapsed` |
| `SizeToContent` + `MaxHeight` 下面几行被顶出去 | 内容行写成了 `Auto`，得给 `*` |
| 按钮文字里的 `_` 不见了 | 访问键助记符，要写 `__` |
| `DataTrigger` 改不动 `Text` | 标签上的本地值优先级高于样式触发器，两个态都得走 `Setter` |
| 隧道事件里 `e.Handled = true` 之后子按钮全哑 | `Preview*` 是从根往下走的，先于目标控件拿到事件 |

## 8. 与提示词的边界

提示词（`Settings/BuiltInModes.cs`）**只管翻译风格，不带任何占位符**。
语言方向由 `PromptBuilder.BuildLanguageInstruction` 单独拼一句，**追加在系统提示词最末尾**。

两条"别改回去"：

1. **必须放最后。** 放在前面会被后面的风格规则覆盖掉。
2. **必须把方向写死**（"本次翻译方向：中文 → 英语"）。
   写成条件句（"如果原文已经是英语就反向翻译"）等于邀请模型自己重新判断一次方向，
   而它判断得没有 `DetectTargetLanguage` 准。原文是外文时写「外文 → 中文」，
   不写具体语种——程序只认得出"是不是中文"，写成「英语 → 中文」遇到法文、日文就是假话。

风格规则里也不能写死中文（"用自然口语化的中文"），要写"目标语言"——
否则译成日语时模型会被那句中文带偏。
