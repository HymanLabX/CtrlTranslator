# 里程碑与验收清单

> 五个里程碑，**必须按顺序做**，做完一个验收一个。
> 验收清单里的每一条，项目负责人都能**不看代码、只靠点鼠标**验证。
> 任何一条不过，就不算这个里程碑完成，不进入下一个。

---

## M0 · 骨架与托盘

**目标**：有一个能编译、能运行、能干净退出的空壳程序。
这个里程碑不做任何划词和翻译功能，专门解决"地基"。

### 交付范围

- `CtrlTranslator.sln` + `src/CtrlTranslator/CtrlTranslator.csproj`
  （`net10.0-windows`、`UseWPF`、`UseWindowsForms`、`nullable enable`、
  `ApplicationIcon`、版本信息）
- `app.manifest`，声明 **Per-Monitor DPI Awareness V2**
- `App.xaml.cs`：
  - **单实例**（用命名 `Mutex`；第二个实例启动时激活已有实例的主窗口后自行退出）
  - **无启动窗口**（`ShutdownMode = OnExplicitShutdown`，启动时不显示任何窗口）
  - 全局异常兜底三件套（见 SPEC §9.3）
- `Diagnostics/Logger.cs`：按天分文件、14 天自动清理、Key 脱敏
- `Settings/AppSettings.cs` + `SettingsStore.cs`：
  JSON 读写、DPAPI 加解密、原子写入、损坏时备份重建
- `Settings/BuiltInModes.cs`：把 SPEC §5.5 的四个内置模式写死为默认值
- `UI/TrayIconController.cs`：托盘图标 + 完整右键菜单（菜单项可点击，
  但"设置""主窗口""诊断"暂时弹一个"该功能将在后续里程碑实现"的提示框即可）
- `Assets/` 下放一个正常图标和一个灰色图标（可以用简单的几何图形自行生成 `.ico`）
- 数据目录自动创建：`%APPDATA%\CtrlTranslator\` 与其下的 `logs\`

## M1 · 划词取词（最难的先攻）

**目标**：双击 Ctrl 能可靠地拿到你选中的文字，并且**不破坏你的剪贴板**。
这个里程碑**不做翻译、不做浮窗**——取到的文字用托盘气泡显示出来即可。

先攻这里是因为：这是整个项目技术风险最高的一环，
如果这里搞不定，后面做再多界面也没意义。

### 交付范围

- `Interop/NativeMethods.cs`：本里程碑需要的所有 Win32 声明
- `Interop/LowLevelKeyboardHook.cs`：`WH_KEYBOARD_LL` 的安装/卸载/回调封装
  （回调必须遵守 AGENTS.md §5.2 的禁区规则）
- `Core/DoubleTapDetector.cs`：SPEC §2.1 的状态机
- `Core/ForegroundApp.cs`：取前台窗口进程名
- `Core/TextCapture.cs`：SPEC §3.1 的完整取词与剪贴板还原流程（含重试）
- `Core/AppState.cs`：全局暂停开关、黑名单检查、防抖
- 取词成功后：托盘气泡显示 `取到 {n} 字：{前50字}`，并写日志
- 设置里的黑名单暂时可以直接改 `settings.json` 手工测试（M3 才做设置界面），
  但**黑名单的读取与判断逻辑必须在本里程碑实现**

### ✅ 验收清单（M1）

| # | 怎么验 | 通过标准 |
|---|---|---|
| 1 | `dotnet build -c Release` | 0 警告 0 错误 |
| 2 | 记事本里打一句话，选中它，快速双击 Ctrl | 右下角气泡显示出你选中的那句话 |
| 3 | 在**浏览器**里选一段网页文字，双击 Ctrl | 能取到 |
| 4 | 在 **Word**（或 WPS）里选一段，双击 Ctrl | 能取到 |
| 5 | 在 **PDF 阅读器**里选一段，双击 Ctrl | 能取到 |
| 6 | 在**微信/QQ**聊天记录里选一段，双击 Ctrl | 能取到 |
| 7 | 🔴 **剪贴板还原测试**：记事本里复制文字 A（Ctrl+C），然后选中另一段文字 B，双击 Ctrl，最后在别处 Ctrl+V | **粘出来必须是 A，不是 B** |

> 这个软件会污染用户的剪贴板，属于**严重缺陷**，必须修好才能继续。

## M2 · 翻译闭环

**目标**：划词 → 翻译 → 浮窗显示。核心价值在这个里程碑跑通。

### 交付范围

- `Translation/OpenAiCompatibleClient.cs`：流式 SSE 解析、单例 HttpClient、
  连接预热与保活、超时与取消（SPEC §5.1 §5.2）
- `Translation/PromptBuilder.cs`：模式模板 + 占位符替换 + 词/句判定 + 语言方向（§3.4 §5.3 §5.4）
- `Translation/ModelHeuristics.cs`：推理模型三重检测（§5.6）
- `Translation/TranslationService.cs`：编排（查缓存 → 请求 → 写库），
  新请求取消旧请求
- `Data/Database.cs` + `HistoryRepository.cs`：建表、缓存查询、写入（§6.2 §6.3）
- `Diagnostics/ErrorMessages.cs`：SPEC §9.1 的**完整**错误映射表
- `Interop/LowLevelMouseHook.cs` + `Interop/DpiHelper.cs`
- `UI/PopupWindow.xaml(.cs)`：SPEC §4 全部内容
  （定位算法、关闭行为、工具条、加载态与计时、流式回退、词典渲染、主题）
- 长文本二次确认对话框（§3.3）
- 浮窗上的 ☆ 收藏按钮本里程碑要能用（写数据库 `starred` 字段），
  但查看收藏的主窗口留到 M3

### 前置条件

验收前需要先手工在 `settings.json` 里填好 Base URL / Key / Model
（Key 要用程序写入，所以本里程碑需要提供一个临时手段：
接受在托盘菜单里加一个临时的「填写 API Key…」输入框，M3 会被正式设置页取代）。
